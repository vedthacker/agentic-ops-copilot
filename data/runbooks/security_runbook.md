# Security Event Runbook

## Phishing and credential exposure
If a staff member or customer clicked a phishing link or entered credentials on a fake page, rotate the credentials immediately, revoke active sessions and enable MFA if it was off. Report the event to security@meridianfreight.example within 1 hour. Open a SEV2 incident; upgrade to SEV1 if customer data was accessed. Do not delete evidence.

## Account lockouts
A user locked out after changing phones needs identity verification by the account owner before an MFA reset. Support agents must never reset MFA based on an email request alone.

## Data deletion requests
Personal data deletion requests must be completed within 30 days by the privacy team. Tax and invoice records are retained for 7 years.
